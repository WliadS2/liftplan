# Simulation

Pure kinematic visualization state, deterministic stepping, structured guards and normalized poses live here. The module has no React, Three.js runtime or Zustand dependency. It consumes read-only render-neutral installation/layout contracts and separately supplied demo/visualization timing; those inputs do not constitute engineering approval.

See [passenger kinematic visualization](../../docs/3d/passenger-kinematic-simulation.md) for the current state machine, explicit 1:1 motion contract, clock and limitations.
