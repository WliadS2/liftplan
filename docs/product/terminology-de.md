# German product terminology

This glossary is the initial source of truth for customer-facing German terminology. Code identifiers remain English. Terms that acquire a regulatory or standard-specific meaning must be reviewed against the applicable authoritative source before use in technical rules.

| German term | Intended product meaning | Usage note |
| --- | --- | --- |
| Aufzug | General term for a lift installation | Preferred generic customer-facing term |
| Personenaufzug | Lift intended for transporting people | Do not shorten to an ambiguous family name |
| Warenaufzug | Lift intended for transporting goods | The distinction from `Lastenaufzug` requires domain confirmation in technical contexts |
| Lastenaufzug | Lift intended for transporting loads | Do not treat as technically interchangeable with `Warenaufzug` without an approved definition |
| Autoaufzug | Lift intended for transporting vehicles | Use as the product-family label |
| Kleingüteraufzug | Lift intended for transporting smaller goods | Do not attach unverified dimensional limits |
| Bettenaufzug | Lift intended to support bed transport | Use as the product-family label |
| Homelift | Lift in the home-lift product family | Keep the established compound noun |
| Plattformlift | Lift using a platform as its transport surface | Use as the product-family label |
| Tragfähigkeit | Approved load capacity of the configured lift | Always display with an explicit unit when a value exists |
| Haltestellen | Served stopping levels | Do not infer the number of doors from this value |
| Förderhöhe | Vertical travel between the defined terminal levels | Always display with an explicit unit when a value exists |
| Kabine | Enclosed carrier space of a lift, where applicable | Do not use for a platform unless the family definition requires it |
| Schacht | Space in which the lift equipment travels or is arranged | Use `Aufzugsschacht` when additional clarity is needed |
| Grube | Lower shaft area below the reference level | Technical dimensions require approved engineering input |
| Schachtkopf | Upper shaft area above the top served level | Technical dimensions require approved engineering input |
| Tür | Generic term for a lift or landing door | Use a more specific approved term when context requires it |
| Antrieb | Drive system of the lift | Do not imply a drive technology unless configured |
| Durchlader | Configuration with access from more than one cabin side | Door arrangement must be explicit in the family configuration |
